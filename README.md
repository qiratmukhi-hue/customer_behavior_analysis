## 🔄 Project Steps

### 1. Data Loading

* Imported the dataset into Python
* Checked dataset dimensions
* Reviewed columns and data types
* Generated initial descriptive statistics

### 2. Exploratory Data Analysis (EDA)

Performed EDA to better understand the dataset.

Key activities included:

* Distribution analysis
* Summary statistics
* Missing value analysis
* Duplicate detection
* Outlier identification
* Category analysis
* Trend analysis
* Relationship analysis between important variables

### 3. Data Cleaning

Prepared the dataset for further analysis by:

* Handling missing values
* Removing duplicate records
* Correcting incorrect data types
* Standardizing column names
* Cleaning inconsistent values
* Handling unnecessary columns
* Preparing a clean dataset for SQL and Power BI

### 4. SQL Analysis

The cleaned dataset was loaded into a relational database.

SQL queries were used to perform:

* Filtering and sorting
* Aggregations using `SUM`, `AVG`, `COUNT`, `MIN`, and `MAX`
* `GROUP BY` analysis
* Conditional analysis
* Joins
* Subqueries
* CTEs
* Window functions
* Business KPI calculations

**Database:** PostgreSQL / MySQL / SQL Server

### 5. Power BI Dashboard

An interactive **Power BI Dashboard** was developed to transform the analyzed data into easy-to-understand visual insights.

The dashboard includes:

* KPI Cards
* Bar and Column Charts
* Line Charts
* Category-wise analysis
* Trend analysis
* Filters and Slicers
* Interactive visualizations

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd Data-Analytics-Project
```

### 2. Install Python Libraries

```bash
pip install pandas numpy matplotlib jupyter
```

### 3. Run the Python Analysis

Open:

```text
notebooks/data_analysis.ipynb
```

Run all cells in **Jupyter Notebook** to perform data loading, cleaning, and EDA.

### 4. Run SQL Analysis

Import the cleaned dataset into:

* PostgreSQL
* MySQL
* SQL Server

Then execute:

```text
sql/analysis_queries.sql
```

### 5. Open the Power BI Dashboard

Open the following file using **Power BI Desktop**:

```text
dashboard/dashboard.pbix
```
